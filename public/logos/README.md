# /public/logos/ — Logos estáticos del Generador de Carteles

Coloca aquí los archivos de imagen para que aparezcan en el canvas.
Formatos recomendados: PNG con fondo transparente o WebP.

## Logos institucionales (carpeta raíz)

| Archivo | Descripción |
|---|---|
| `xunta-galicia.png` | Logo Xunta de Galicia (arriba izquierda) |
| `rfgf.png` | Logo RFGF — Real Federación Galega de Fútbol (arriba derecha) |
| `santiso.png` | Escudo UD Santiso FC (siempre presente en el cartel) |

## Logos de patrocinadores (subcarpeta /sponsors/)
